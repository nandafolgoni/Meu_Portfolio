Portfólio-Currículo Web

📋 Sobre o Projeto

Este projeto consiste no desenvolvimento de uma página de Portfólio /
Currículo Web para apresentar informações pessoais, habilidades,
projetos e formas de contato de uma desenvolvedora web.

A página foi desenvolvida utilizando HTML5 puro e semântico,
seguindo a estrutura e os requisitos propostos no desafio.

🎯 Objetivo

O objetivo do projeto é demonstrar o domínio da estruturação de páginas
Web com HTML, utilizando elementos semânticos, navegação interna,
tabelas, imagens e formulários.

🛠️ Tecnologias Utilizadas

HTML5

Estrutura semântica

Links e âncoras internas

Tabelas HTML

Formulários HTML

Imagens

📌 Estrutura da Página

Cabeçalho e Navegação

O cabeçalho apresenta o nome e a função da desenvolvedora, além de um
menu de navegação com links para as principais seções da página:

Sobre

Projetos

Contato

Sobre Mim

A seção apresenta uma breve descrição da desenvolvedora, sua formação e
conhecimentos em desenvolvimento Web.

Também contém uma imagem de perfil configurada com 150 x 150 pixels
e uma lista com as principais habilidades:

HTML5 Semântico

CSS3 e Responsividade

Formulários e Validação

Estruturação de Dados

Meus Projetos

Os projetos são apresentados em uma tabela organizada com as seguintes
informações:

Projeto

Tecnologias

Status

Link

Atualmente, a página apresenta os seguintes projetos:

Projeto               Tecnologias             Status

Itaú                  HTML, CSS               Concluído
Projeto Filme         HTML, CSS, JavaScript   Concluído
Loja de Games Retrô   HTML, CSS, JavaScript   Concluído

Cada projeto possui um link para seu respectivo repositório no GitHub.

Entre em Contato

A seção de contato possui um formulário agrupado por meio das tags
<fieldset> e <legend>.

O formulário contém:

Nome completo

E-mail

Assunto

Mensagem

Botão para envio

Os campos possuem seus respectivos <label> vinculados aos elementos de
entrada.

Rodapé

O rodapé apresenta informações de direitos autorais, e-mail e telefone
para contato, utilizando o caractere especial &copy;.

🧱 Elementos HTML Utilizados

O projeto utiliza diferentes elementos do HTML5, incluindo:

<header> para o cabeçalho;

<nav> para a navegação;

<main> e <section> para organização do conteúdo;

<h1>, <h2> e <h3> para títulos;

<img> para a imagem de perfil;

<ul> e <li> para listas;

<table>, <thead>, <tbody>, <tr>, <th> e <td> para a
tabela de projetos;

<form> para o formulário;

<fieldset> e <legend> para agrupamento dos dados de contato;

<label>, <input>, <select>, <textarea> e <button> para os
campos do formulário;

<footer> para o rodapé.

▶️ Como Executar

Baixe ou clone este repositório.

Mantenha a estrutura de pastas do projeto, incluindo a pasta
assets e a imagem utilizada na página.

Abra o arquivo portfolio.html em um navegador.

Utilize o menu de navegação para acessar as seções da página.
